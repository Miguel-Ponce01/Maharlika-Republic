**TO WHOM IT MAY CONCERN:**

This is to certify that we, the owners and management of **Maharlika Marexx Republic Davao**, do hereby formally accept the **Maharlika Republic Platform**, a hybrid e-commerce catalog and physical showroom locator system. The platform was designed, developed, and delivered by the following students of Mapúa Malayan Colleges Mindanao:

1. **ANTHON MIGUEL B. PONCE** — Project Manager / Lead Developer
2. **PRINCESS JELYN MAE S. VILLARAIZ** — Systems Analyst / QA Tester

This acceptance is based on the successful demonstration, validation, and testing of the following core modules:
- **Premium E-Commerce Showcase:** Dynamic product catalog displaying live inventory variants.
- **Interactive Dual-Canvas Showroom Map:** Location-based showroom finder built with MapLibre GL for both Bajada building locator (macro) and indoor floor layout (micro).
- **Zustand Shopping Pipeline:** Persistent cart drawer and responsive user checkout workflow.
- **Messenger Invoice Dispatch:** Clipboard payload generation that structures invoice data for quick Facebook Messenger transmission.
- **Supabase Authentication Hub:** Secure user registration, profiles, and order tracking.
- **Admin Dashboard & Backoffice:** Live product editing, variant configurations, and revenue diagnostics.

We confirm that all functional requirements have been met, UAT tests have successfully passed, and complete documentation and training have been handed over. We recommend that the developers receive full academic credit for this implementation.

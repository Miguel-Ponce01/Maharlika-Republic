We hereby **ACCEPT** the completed project with the following verified features:
1. **Customer-Facing Storefront:** Sleek, adaptive dark/light themed interface with Outfit typography and floating showcase animations.
2. **Inventory Management:** Database-driven variant listing with real-time stock-on-hand tracking.
3. **Point-of-Sale (POS) & Checkout:** Checkout form supporting GCash, Maya, and cash payments with custom shipping fee calculators.
4. **Interactive Location Mapping:** Dual-canvas MapLibre GL implementation matching the Bajada macro showroom locator with the micro indoor showroom layout.
5. **Flexible Payment Option Guides:** Instagram-style visual highlights displaying layout and details for lay-away and partner installment schemes (Salmon, Skyro).
6. **Messenger-Based Transaction Dispatch:** Checkout generator generating formatted, one-click copyable order invoices for manual validation via Messenger.
7. **Customer Accounts:** Supabase authenticated accounts showing persistent order histories.
8. **Admin Dashboard:** Overview dashboard providing active order numbers, low-stock warnings, and revenue updates.

The system has undergone full User Acceptance Testing (UAT) and staff training. We have found it to be fully functional, accurate, and beneficial to our daily operations. It effectively solves our initial problems regarding:
*   Manual inventory discrepancies and stock tracking errors.
*   Limited online discoverability due to the lack of a structured, dedicated catalog.
*   Lack of transparency and customer friction regarding flexible financing options.
*   Navigation difficulties in finding the showroom inside the Bajada building.

We look forward to utilizing this system in our daily operations and recommend that the students be given full academic credit for the successful completion of this project.
